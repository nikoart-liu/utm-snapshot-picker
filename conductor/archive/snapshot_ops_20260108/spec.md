# Track Spec: 实现创建快照、删除快照、回滚快照功能

## 目标
在当前快照浏览器的基础上，添加完整的快照生命周期管理功能：创建、删除和回滚。

## 核心功能
1. **创建快照 (Create Snapshot)**:
   - 按钮位置：虚拟机详情页顶部工具栏。
   - 交互：点击后弹出 macOS 风格的对话框，要求输入 **快照名称** 和 **描述（备注）**。
   - 后端实现：调用 `qemu-img snapshot -c <name> <disk_path>`。

2. **删除快照 (Delete Snapshot)**:
   - 触发方式：选中快照后，点击列表底部的“删除”按钮。
   - 安全性：删除前弹出确认对话框。
   - 后端实现：调用 `qemu-img snapshot -d <name> <disk_path>`。

3. **回滚快照 (Revert to Snapshot)**:
   - 触发方式：选中快照后，点击列表底部的“回滚”按钮。
   - 安全性：**强制拦截**。如果虚拟机正在运行（通过之前实现的 `is_running` 检测），则禁用回滚按钮并提示用户关闭虚拟机。
   - 后端实现：调用 `qemu-img snapshot -a <name> <disk_path>`。

## UI 交互
- **工具栏**：在详情页顶部添加“+”图标按钮。
- **列表控制**：在快照表格下方添加一个细长的操作栏（Action Bar），包含“回滚”和“删除”按钮，仅在选中行时激活。
- **对话框**：使用 Tauri 的对话框插件或自定义极简 React 组件实现输入窗口。

## 验收标准
- [ ] 能够成功为正在运行或关闭的虚拟机创建带自定义名称的快照。
- [ ] 能够删除选中的快照，且列表实时刷新。
- [ ] 当虚拟机运行时，回滚按钮必须处于禁用状态（Disabled）。
- [ ] 当虚拟机关闭时，回滚操作能成功将虚拟机状态恢复到指定快照。
