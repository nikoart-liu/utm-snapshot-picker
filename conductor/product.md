# Initial Concept
创建一个macos上的utm虚拟机快照管理工具，使用qemu-img实现

# 产品愿景
开发一个专为 macOS 用户设计的 UTM 虚拟机快照管理工具，通过封装复杂的 `qemu-img` 命令行操作，提供直观、安全的界面，解决 UTM 原生界面在快照管理功能上的不足。

# 核心价值
- **简化操作**：将复杂的 `qemu-img` 命令转化为一键式操作。
- **可视化管理**：提供清晰的快照列表展示。
- **安全性**：自动检测虚拟机运行状态，防止危险操作。

# 已实现功能
- **虚拟机扫描**：自动扫描并列出 macOS 系统标准路径下的 UTM 虚拟机。
- **运行状态检测**：实时显示虚拟机是否正在运行。
- **快照解析**：智能识别虚拟机磁盘并读取其快照元数据（名称、创建日期、大小）。
- **原生感 UI**：基于 macOS 设计语言的侧边栏与详情页布局，支持深色模式和刷新功能。
- **生命周期管理**：支持创建新快照、删除旧快照。
- **一键回滚**：支持回滚到指定快照状态。
- **安全策略**：在虚拟机运行时自动拦截创建和回滚操作，防止数据损坏。
