# Track Spec: 标识虚拟机当前快照状态 (HEAD Tracking)

## 目标
在快照列表中清晰地标识出虚拟机当前“基于”哪一个快照状态，帮助用户在复杂的快照树中辨别方位。

## 核心功能
1. **HEAD 追踪逻辑**:
   - 当用户执行 **Revert** 操作成功后，将目标快照 ID 记录为该虚拟机的 `current_head`。
   - 当用户执行 **Create Snapshot** 操作成功后，将新创建的快照 ID 记录为新的 `current_head`。
   - 记录应针对每个虚拟机路径 (`vm_path`) 独立保存。

2. **持久化存储**:
   - 引入 `tauri-plugin-store`。
   - 将 `current_head` 映射关系持久化到磁盘，确保应用重启后标识不丢失。

3. **UI 展示**:
   - 在快照表格中，为匹配 `current_head` 的行显示一个醒目的图标指示器。
   - 视觉形式：在快照名称左侧显示一个带圆圈的箭头图标 `➔` 或 `HEAD` 胶囊标签。

## 技术细节
- **Tauri 插件**: 安装并配置 `tauri-plugin-store` 用于 Rust 和前端的状态同步。
- **状态同步**: 
  - 前端加载 VM 时，从 Store 读取对应的快照 ID。
  - 前端执行操作成功后，更新 Store。

## 验收标准
- [ ] 应用重启后，之前标记的“当前快照”依然能被正确识别和高亮。
- [ ] 切换不同的虚拟机，各自的“当前快照”标识独立更新。
- [ ] 执行 Revert 到旧快照后，标识符立即跳转到该快照行。
- [ ] 创建新快照后，标识符立即移动到新创建的行。
