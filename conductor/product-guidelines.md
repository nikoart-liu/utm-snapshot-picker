# 产品准则

这些准则定义了 UTM 快照管理工具的设计哲学、用户体验目标和视觉风格。

## 视觉与 UI 风格
- **极简原生感**：界面应遵循 macOS 的设计语言。使用原生的 UI 组件、SF Symbols 图标以及系统标准的边距和配色方案，使应用看起来像是 macOS 的一部分。
- **专注核心**：界面不应被次要信息充斥，首要任务是让用户能够快速定位虚拟机并执行快照操作。

## 交互设计
- **简洁明了**：遵循“少即是多”原则。仅在必要时显示通知或反馈，避免冗余的确认弹窗。
- **直接操作**：用户对快照树的操作应尽可能直观，例如通过简单的点击或右键菜单完成回滚 and 删除。

## 语气与表达
- **专业且简练**：文案应保持专业、客观，避免过度修饰。
- **清晰的反馈**：当操作成功或失败时，提供简短、明确的提示，确保用户了解当前系统状态。
